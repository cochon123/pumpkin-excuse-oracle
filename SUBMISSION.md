# Devpost — Pumpkin Excuse Oracle
**Tagline:** The pumpkin has never been wrong. (It has always been wrong.)
## Inspiration
Midterm season + spooky season = everyone needs an excuse. We wanted the least useful productivity tool ever made.
## What it does
Type the thing you didn't do; poke the pumpkin; it shakes, morphs into a ghost or bat, plays a creepy synth slide, and serves a randomly assembled excuse ("three raccoons in a trench coat possessed my lab report while humming the Monster Mash") with a believability score you should not trust.
## How we built it
HTML/CSS/JS; Web Audio API oscillator for the sound; CSS keyframes for the shake; combinatorial word lists (8×8×6 = 384 excuses). Built with help from an AI coding assistant.
## Challenges
Restarting a CSS animation on every click; browsers blocking audio until a user gesture.
## What we learned
Web Audio basics and that writing funny content is harder than writing code.
## What's next
More monsters, a "send to prof" button that refuses to work, user-submitted excuses.
## Built with
html, css, javascript, web-audio-api
